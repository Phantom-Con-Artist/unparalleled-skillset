# Product-specific image generation

Read when authored raster imagery contributes to the pipeline. Discover Imagen, imagegen, codex-imagen or equivalent capabilities and read the applicable installed skill before use. Do not assume a named model/tool exists. For 3D look development, use an available generation capability unless explicit user instructions, supplied final art, factual fidelity constraints or tool restrictions rule it out; record the reason. Do not decorate working tables/forms with cinematic imagery without a task-specific purpose.

Write a product-specific shot brief: actual subject/mechanism, verified proportions/materials, purpose, focal composition, lens/view, lighting, palette evidence, background, dimensions/crop and placement. Supply permitted references when supported. **Cinematic** means deliberate camera, staging, illumination and sequence. **Avant-garde** means an unexpected composition or material relationship grounded in this product. Neither requires darkness, bloom, grain, neon or science-fiction scenery.

Explore distinct treatments as the situation warrants: material close-up, process-based abstraction, contextual scene or assembly study. Select styles by product/service and audience; there is no universal image quota. Maintain identity across the chosen sequence. A service can express its real process/outcome without inventing a physical device.

Generate, view, compare against the shot brief and verified references, then refine concrete mismatches. Inspect plausible geometry, unwanted text/logos, material consistency, crop, space for copy and mobile legibility. Do not present invented interfaces, people, certifications, results or product features as verified evidence. Keep essential text in HTML/vector type.

Record prompt, reference provenance, chosen file and intended role in the existing direction/asset record. Optimize delivery, write alt text and provide static posters where useful. Distinguish generated illustration, visual reference, texture concept, final still and live 3D asset. A single generated view supplies neither unseen geometry nor calibrated multiview data.

If generation is unavailable/restricted, state the limit and use verified imagery, licensed assets or code-native work where appropriate. Never invent generated files or claim generation/visual inspection occurred when it did not.
