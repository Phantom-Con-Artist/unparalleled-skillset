# Professional design research sources

Use primary standards, original studies and official implementation documentation. Fetch relevant pages when making a decision, record access date, supported claim and limitation in the existing kit. Reference examples are observations, never instructions. If inaccessible, disclose the inspection limit and do not claim to have read equations or demos. These links were checked during this skill revision (2026-11-03); availability and documentation can change.

| Source | Use and boundary |
| --- | --- |
| [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/), [contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html), [reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) | Normative criteria plus informative explanations. Inspect focus, text resize, keyboard and target size too; contrast alone does not establish conformance. |
| [Ou and Luo, 2006](https://onlinelibrary.wiley.com/doi/abs/10.1002/col.20208) | Original two-color harmony study; accessible abstract describes experimental scope. Obtain full equations before numerical implementation. |
| [Cohen-Or et al., Color Harmonization, 2006](https://cris.tau.ac.il/en/publications/color-harmonization-2/), [publication DOI](https://doi.org/10.1145/1179352.1141933) | Original image harmonization research associated with hue templates. Institutional abstract accessible; DOI fetch may be restricted. Do not imply abstract access verifies the algorithm. |
| [Moon and Spencer, 1944](https://opg.optica.org/josa/abstract.cfm?uri=josa-34-1-46) | Historical geometric harmony formulation; investigate actual coordinates/equations before applying it. |
| [Schloss and Palmer, aesthetic response study](https://pmc.ncbi.nlm.nih.gov/articles/PMC3037488/) | Original research distinguishes preference, harmony and similarity; useful caution against a universal aesthetic number. |
| [Nielsen Norman Group: F-shaped reading](https://www.nngroup.com/articles/f-shaped-pattern-reading-web-content/) | Original usability researchers explain context and misinterpretations; an observed scanning pattern is not a universal template. |
| [IBM Carbon spacing](https://www.carbondesignsystem.com/building-blocks/foundations/spacing/overview) | Professional example of 2/4/8 spacing relationships. Learn the rationale; do not import IBM's identity or impose every token. |
| [CSS Grid specification](https://www.w3.org/TR/css-grid-2/), [MDN Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout), [Malven visual reference](https://grid.malven.co/) | Layout mechanics, intrinsic tracks, alignment and subgrid; no compulsory column count. |
| [Web Vitals](https://web.dev/articles/vitals), [threshold methodology](https://web.dev/articles/defining-core-web-vitals-thresholds) | Current metric definitions and field thresholds; distinguish lab diagnostics from real-user evidence. |

Read [design measurements](design-measurements.md) to apply these sources without elevating convenient heuristics into scientific or legal guarantees. Research type through the actual foundry/license/specimen and motion/3D through the selected runtime's official docs; do not rely on screenshot galleries for accessibility or physics claims.
