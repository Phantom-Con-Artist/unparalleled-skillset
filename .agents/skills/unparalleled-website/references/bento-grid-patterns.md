# Compose relationships instead of card grids

This filename is retained for existing links. Bento is no longer a required remedy for generic cards. Do not replace every three-card row with the same asymmetric grid.

Use layout to express a product relationship: sequence, dependency, comparison, transformation, or scale. CSS Grid remains useful infrastructure; rounded feature cells are not a design concept. Prefer an annotated working demonstration or connected spatial story when it communicates more than a group of containers.

Keep DOM reading order meaningful, collapse gracefully on narrow screens, and preserve keyboard access. Do not use dense visual packing or out-of-order placement that makes content incomprehensible to assistive technology. Use [narrative-structure.md](narrative-structure.md) to determine the information sequence first.
