# 10 Distinctive Hero Architectures (Replacing the Generic Centered 3-Liner)

Never default to a centered 3-line headline over a blurry pastel gradient. Select one of these 10 intentional hero architectures:

---

### 1. The Asymmetric Split with Live Product Fragment
- **Left (55%)**: Huge fluid headline, punchy single-sentence subhead, primary CTA pill + secondary video trigger, micro-trust avatars.
- **Right (45%)**: A high-fidelity, interactive fragment of the actual product (live code editor, data card, or telemetry chart) floating with subtle tilt and hairline border.

### 2. The Typographic Monument
- **Layout**: Full-width monumental display typography (`clamp(3.5rem, 11vw, 10rem)`) spanning edge-to-edge.
- **Cadence**: First line left-aligned, second line right-aligned with an interactive pill button nested inside the typographic indent.

### 3. The Bento Mosaic Hero
- **Layout**: A 4-cell Bento grid where the hero headline lives in the top-left double cell, real-time social proof occupies the top-right, a live interactive demo fills the bottom-left, and a customer quote sits in the bottom-right.

### 4. The Terminal / Technical Canvas
- **Layout**: Clean monochromatic workspace with a floating command terminal or IDE snippet as the centerpiece.
- **Features**: Copy-paste install command (`npm i ...` or `npx ...`), live syntax highlighting, active branch/status badges.

### 5. The Editorial Dual-Column
- **Layout**: Inspired by high-end print magazines.
- **Left (40%)**: Elegant serif headline, issue number, metadata date, author/founder signature.
- **Right (60%)**: Large full-bleed image with an overlapping pull-quote card.

### 6. The Interactive Sandbox Hero
- **Layout**: Headline above an immediately interactive canvas where the user can drag, toggle, customize, or preview the product directly on first load without signing up.

### 7. The Video / 3D Spatial Canvas
- **Layout**: Ambient looping video or 3D canvas background with dark scrim gradient overlay. Content is docked in the lower third with high-contrast typography and clear call-to-action.

### 8. The Metric-Driven Monument
- **Layout**: Giant numerical impact metric (e.g. `99.999%` or `0.04ms`) set in giant tabular display typography with supporting technical claims and architectural badges.

### 9. The Floating Card Showcase
- **Layout**: Centered bold headline flanked by 3 distinct floating cards (one showing an integration, one showing a security badge, one showing live analytics) anchored at slight rotational offsets (`rotate(-2deg)`, `rotate(3deg)`).

### 10. The Conversational Dialogue Hero
- **Layout**: A simulated high-speed interaction dialogue showing the problem and solution in real time before revealing the primary product action.
