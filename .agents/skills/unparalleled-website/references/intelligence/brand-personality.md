# Brand personality intelligence

Brand personality is the set of human traits the product should be recognized by, expressed consistently in voice, color, type, shape, imagery and motion. A professional defines a few specific traits from evidence, makes each trait a design rule, and checks that no competitor could claim the same expression by swapping a logo.

This is step 0 of design.md: every later discipline cites these traits.

## What the discipline decides

- **Evidence**: what the product actually does, for whom, its history, materials, existing brand assets and commitments (all from product.md).
- **Traits**: 3–5 specific traits, each with an opposite it is **not** (for example "exacting, not cold"; "warm, not cute"). Trait pairs stop drift.
- **Voice and tone**: position on NN/g's four tone dimensions (funny ↔ serious, formal ↔ casual, respectful ↔ irreverent, enthusiastic ↔ matter-of-fact), and how tone shifts by context (error messages vs a hero headline).
- **Expression map**: how each trait shows in every discipline (trait → color terms for the Color Intelligence Layer, type forms, geometry, image style, motion character, copy rules).
- **Existing commitments**: logo, brand colors, fonts, guidelines the user already has. These win over new ideas.
- **Differentiation**: the closest competitors and what this product's expression does that theirs does not.

## Standards and data

| Source | What it settles |
| --- | --- |
| Aaker (1997), "Dimensions of Brand Personality", *Journal of Marketing Research* | Five research-derived dimensions: sincerity, excitement, competence, sophistication, ruggedness. A vocabulary, not a template. |
| NN/g, "The four dimensions of tone of voice" | A measurable way to describe and keep a consistent voice. |
| Mailchimp Content Style Guide, voice and tone | A professional example of voice that stays constant while tone adapts to context. |
| NN/g aesthetic-usability effect | Users perceive attractive, coherent designs as easier to use, which raises the stakes of consistency. |

## Allowed practice

- Traits derived from product.md facts and vocabulary, each with its evidence.
- Trait pairs ("X, not Y") that make the boundary explicit.
- Translating traits into Color Intelligence vocabulary terms with weights (for example "exacting" → `precise:2`, "warm" → `warm:1`), checked against the engine's `limitation` notes.
- A small set of brand signatures used consistently: a shape logic, a color moment, a type behavior, an illustration grammar, a motion character.
- Brand archetypes or Aaker dimensions as a vocabulary for discussion with the user, if they help.
- Voice examples: the same message written in the chosen tone for a headline, a button, an error and an empty state.

## Banned practice

- Adjective soup with no evidence ("innovative, modern, premium, trusted").
- Traits that any competitor would also claim, with no product-specific expression.
- Choosing an archetype or genre first and forcing the product into it.
- Personality expressed only in the hero and absent from forms, errors, navigation and the footer.
- Fabricated brand stories: invented founders, histories, awards, customer counts or quotes.
- Copy clichés: "unlock", "elevate", "empower", "seamless", "next-gen", "all-in-one", "where X meets Y", formulaic "Not X. Y." contrasts, em-dash habits. See [human-writing.md](../human-writing.md).
- Overriding an existing brand system the user did not ask to change.
- Handwriting fonts, sketch textures or wobble as the expression of "human" or "handcrafted" when the brief did not literally ask for handmade work.

## Record in design.md (Brand personality section)

Evidence list (linked to product.md); 3–5 trait pairs; tone position on the four dimensions; expression map table (trait → color terms → type → geometry → imagery → motion → copy); existing commitments; competitor swap test written out.

## Verify

1. **Swap test**: replace the name and logo with the closest competitor's. If the design still fits them, the expression is not specific enough.
2. Read the hero, a button, an error and the footer aloud: same voice, appropriate tone.
3. Each later design.md section cites at least one trait it expresses.
