# The 5 Radically Different Specimen Rule

> *"Never present five variations of the same layout with tweaked button colors. True creative direction presents five fundamentally distinct architectural convictions, each exploring a divergent aesthetic philosophy."*

---

## 1. The Core Specimen Mandate

When the user asks for design options, the agent must generate a single interactive HTML file (`design-specimens.html`) that can open directly in Google Chrome or any web browser.

The specimen file must contain **at least 5 radically distinct designs**, each scored and annotated:

| Specimen # | Fundamental Aesthetic Archetype | Key Distinction | Typography Pairing | Interaction & Depth |
|---|---|---|---|---|
| **Specimen 1: The Monument** | High-Contrast International / Swiss | Giant typographic scale, mathematical 12-column grid, razor-sharp hairline dividers, zero drop shadows. | Monolithic Grotesque (PP Neue Montreal / Neue Haas) + Geometric Mono | Crisp horizontal scrub & baseline snap |
| **Specimen 2: The Dark Monolith** | Linear / Obsidian Tech | Deep obsidian surfaces, subtle 3D interactive card tilt, radial ambient backlights, neon laser punch accent. | Geist Sans + Geist Mono | Interactive 3D cursor tilt with specular rim highlights |
| **Specimen 3: The Editorial Artisan** | Warm Literary Luxe | Warm alabaster / linen canvas, asymmetric multi-column editorial balance, large serif titles, pulling quotes. | High-Contrast Serif (Newsreader / Instrument Serif) + Neutral Sans | Gentle fluid fades, organic grain overlay |
| **Specimen 4: The Tactile Kinetic** | Neo-Brutalism & Kinetic Pop | Solid 2.5px stark outlines, hard 4px offset drop shadows, floating badge stickers, marquee tickers, high energy. | Space Grotesk / Syne + JetBrains Mono | Magnetic button snap, spring press physics |
| **Specimen 5: The Spatial Atmospheric** | Humanist Spatial / Modern Glass | Multi-layered frosted glass panels, ambient colored glow meshes, soft rounded pills, expansive negative space. | Plus Jakarta Sans / Outfit + Clean Sans | Smooth spring inertia scroll, backdrop blur depth |

---

## 2. Product Matching Score & Recommendation Matrix

Each specimen must be accompanied by:
1. **The Product Matching Score (0–100%)**:
   - Evaluates how deeply this specific archetype amplifies the core proposition of the product or service.
   - Example: A developer infrastructure tool scores 96% on Dark Monolith, 78% on Editorial Luxe, and 62% on Neo-Brutalism.
2. **The Creative Recommendation**:
   - One specimen is marked as **"★ Recommended / Primary Conviction"** with an articulate, 2-paragraph rationale explaining why this exact architectural choice best positions the product against competitors.
3. **Vocabulary Alignment Rationale**:
   - Explicitly cites which terms from the Vocabulary Aesthetic Book are embodied by this design.

---

## 3. The Interactive Specimen Switcher

The generated `design-specimens.html` must include a floating, accessible navigation dock allowing the user to:
- Instantly switch between all 5 designs with smooth transitions.
- View the Matching Score, Archetype name, and Rationale panel.
- Easily select and approve their favorite design.
