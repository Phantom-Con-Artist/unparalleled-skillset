# Website run

Read [SKILL.md](../SKILL.md) for the eight-phase protocol. Scale the work to the authorized scope; preserve existing user preferences and brand commitments.

## Understand and align

Read code and assets, verify product facts, and inspect relevant competitors with available tools. Write `prospective-design.md`, distinguish evidence from assumptions, and ask only unanswered questions. Offer a skip option and continue from a sufficient brief when authorized.

## Derive and explore

Extract the vocabulary, write the human voice, derive distinctive type and a justified palette, and draw the bespoke icon grammar. Storyboard meaningful 2D/3D relationships and motion beats with static equivalents. Generate five distinct, live hypotheses in `design-specimens.html`, with reasoned fit scores and a recommendation. Do not choose a mainstream genre or prefilled template.

## Build and verify

Build the selected or authorized recommended direction. Keep native scroll, semantic structure, content-first loading, complete control states, and inclusive motion fallbacks. Test real computed colors, narrow and wide screens, keyboard, touch, font failure, media failure, and the primary action. The sample contrast fixtures do not certify a site.

## Review and finish

Request the independent review described in [subagent-review-rubric.md](../references/subagent-review-rubric.md). Fix hard failures, perform a final focused review, and report the result. Preserve intentional, useful irregularities. Finish when the quality gate is met instead of pursuing endless perfection.
