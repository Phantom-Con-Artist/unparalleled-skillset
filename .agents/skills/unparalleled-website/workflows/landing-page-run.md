# Workflow: The Landing Page Run

Follow this 6-step run to design and build an award-winning website or landing page:

---

## Step 1: Inventory the Subject
- [ ] What is the subject's exact name and purpose?
- [ ] What 8–10 concrete attributes exist? (metrics, materials, origin, rituals, constraints).
- [ ] What is the single primary conversion action?

## Step 2: Choose Archetype & Palette
- [ ] Select archetype from `references/aesthetic-archetypes.md`.
- [ ] Set up CSS custom properties in OKLCH: canvas, surfaces, text, hairline borders, punch accent.
- [ ] Run `npm run check-contrast` to verify compliance.

## Step 3: Establish Fluid Typography
- [ ] Import display and body font pairings.
- [ ] Configure fluid clamp variables for hero, H1, H2, body, and labels.

## Step 4: Craft the Hero Architecture
- [ ] Select an intentional hero architecture from `references/hero-architectures.md`.
- [ ] Build the interactive fragment or visual preview.

## Step 5: Construct the Bento Grid & Cadence
- [ ] Implement the asymmetrical bento grid (`references/bento-grid-patterns.md`).
- [ ] Add the editorial conviction quote and social proof band.
- [ ] Anchor with the high-contrast CTA section.

## Step 6: Polish Motion & Quality Gate
- [ ] Add spring physics micro-interactions to buttons and cards.
- [ ] Audit against `references/anti-slop-invariants.md`.
- [ ] Run `npm run validate-skill`.
