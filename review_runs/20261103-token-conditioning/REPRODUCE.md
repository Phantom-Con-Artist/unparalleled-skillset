# Reproducing the research

Use the versioned source with Python 3.11 or later and the project requirements. The fitted experiment used Python 3.14.8; exact scientific-package versions are in [software_versions.json](./software_versions.json). Poppler's `pdftotext` is required for source extraction. No paid API or GPU is used.

Model artifacts are locally fitted joblib bundles. Load only bundles generated by this experiment; remote model or pickle files are not downloaded or executed. Full source copies and datasets remain local, while their pinned URLs and hashes are versioned.

## Fresh acquisition

Choose a directory that does not exist. The helper refuses to overwrite an existing run and records failures without deleting successful downloads.

```bash
python3 scripts/fetch_token_research_sources.py --output review_runs/token-study-new
mkdir -p review_runs/token-study-new/logs
```

This fetches the nine PDFs, technical pages, and three CSVs pinned to the authors' repository revision. Original acquisition records are preserved in the source manifests beside this file. The original Google Drive URL was unavailable; the CSVs used in the experiment are available from the 2023 paper's official repository.

## Fixed comparison

From the repository root:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLCONFIGDIR=/tmp/color-engine-mpl \
  python3 -m research.token_conditioning.experiment \
  --data review_runs/token-study-new/datasets \
  --output review_runs/token-study-new/experiment-01 \
  > review_runs/token-study-new/logs/experiment-01.log 2>&1
```

The script validates the source rows, fixes leakage-controlled splits, fits models on training only, selects hyperparameters on validation, and writes `selection_frozen_before_test.json` before evaluating test queries. It also saves local fitted models and raw predictions. The [fixed protocol](./PROTOCOL.md) describes the choices and metrics. Source snapshots in the original experiment preserve the exact fitting code.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
```

## Weighted-token prototype

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MPLCONFIGDIR=/tmp/color-engine-mpl \
  python3 -m research.token_conditioning.prototype \
  --bundle review_runs/token-study-new/experiment-01/models/research_bundle.joblib \
  --targets '{"neon":0.6,"calm":0.4}' \
  --theme dark --allow-background-changes \
  --output review_runs/token-study-new/example-neon-calm.json
```

Input weights are relative, finite, and non-negative, with at least one positive value. Unsupported or partially supported concept requests return `unsupported_tokens` without generating a substitute. Optional methods are `ridge`, `mlp_generation`, `tfidf`, `graph`, and `neural_retrieval`; the default uses the frozen validation-selected conditional method. Neural generation has at most three initialization variants, not unlimited random sampling.

A successful output contains `roles`, `button_label`, `audits`, `changes`, numerical targets, coverage, and explicitly experimental similarities. `aesthetic_confidence` remains null. The fixed typography context is 16px/400 body text with an APCA Lc90 target; the prototype is not a replacement for arbitrary-role production audits.

Additional background adjustment is disabled unless `--allow-background-changes` is present. Even the foreground-only stage applies the declared light/dark canvas/surface priors; the flag controls further movement toward white/black when foreground targets are infeasible.

## Tests

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLCONFIGDIR=/tmp/color-engine-mpl \
  python3 -m unittest discover -s tests -v
python3 test_color_engine.py
```

Tests do not download data or fit the full research models. They check graph behavior, feature permutation invariance, vectorized conversion against the engine, unknown-token rejection, explicit permission for background fallback, uncalibrated-score metadata, and actual emitted-color contrast. Existing engine regressions run alongside the new tests.

The experiment's predictive results were measured on Python 3.14.8 with the saved package versions. Cross-version unit checks do not imply identical fitted coefficients or model-bundle compatibility across different scikit-learn versions.
