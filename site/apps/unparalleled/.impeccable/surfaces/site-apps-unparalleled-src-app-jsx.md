# Unparalleled website

Scope: the public site at `/` (source `site/apps/unparalleled`), with the demos it links to at `/poterie-celeste/` and `/claude/`. Visitor mode: Persuade.

Audience and job: developers and designers who build interfaces with AI coding agents and want output that does not look generated. Action: copy the install command. Proof: the two demos (one made from a single prompt), the capture report's real flag list, the supported-agent table. Constraints: no invented users, stars, testimonials, benchmarks or awards; the site must pass its own capture flags.

## Direction contract

THESIS: The site is a toile, the plain muslin mock-up a couturier cuts, pins and corrects before cutting real cloth. A generic generated page is pinned up as the muslin, the skill's screenshot loop marks every template tell on it in chalk, and the fitted result is cut in cloth. It refuses the developer-tool default of a dark terminal hero with a feature-card row.

OWN-WORLD: Kraft pattern paper as the ground, printed with a dot-and-cross grid; ink black for print; tailor's chalk blue for corrections; red tacking thread for the one active mark; tape-measure yellow for the command. Pattern-piece shapes with notches, grainline arrows and dotted cutting lines frame content instead of cards. Type is Archivo across its width axis, condensed for envelope headings and normal for reading, with Martian Mono only for commands. Corners are square and cut, never rounded.

STORY: The visitor reads what Unparalleled is and copies the command, watches a generic page get fitted correction by correction, sees two real sites cut from the skills, one from a single sentence, compares the two views (website, ui), checks their agent in the size chart, and leaves with the command.

FIRST VIEWPORT: Left: the wordmark set wide and heavy, one plain sentence on what the skills do, the install command on a yellow tape strip with a copy control, and links to the demos. Right: a generic landing page pinned to the paper as unbleached muslin, its template tells circled and labelled in chalk.

FORM: The couturier's toile, candidate 6 of 7 on the ordered list. seed:0e23288397cb7ea6

Raises from declined challengers: nothing is enclosed in a box, structure comes from pattern-piece edges (cracktro); stepped test strips preview a choice before committing, used for the five hypotheses (darkroom); the grid breaks only where a correction is being made (raygun); a wordmark built to survive scale-down (skate deck wall). Competitive alternate kept: the industrial quote grammar, which names each tell literally.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
